# ADR-0003: 施設名検索を Yahoo! ローカルサーチ API に切り替え

- 日付: 2026-10-18
- 状態: 採用（[ADR-0002](0002-poi-geocoder.md) を置換）

## 背景

ADR-0002 で施設名検索に Nominatim 公式インスタンスを採用した。使い始めてすぐ、ある事業所（「○○（株）△△事業所」の形の名称）が候補に出ないことが分かった。クエリの整形が原因ではない。OSM にこの施設が登録されていない（Overpass で周辺を社名・事業所名で引いても該当なし）。Nominatim は OSM データしか持たないので、どう整形しても見つからない。事業所・個人商店は OSM の収録率が低く、同じ取りこぼしは今後も起きる。

必要な能力は変わらない。日本語の施設名から座標を返すこと。変わったのは、データの収録範囲を Google Maps に近づける必要があると分かった点。

## 検討した選択肢

- **Yahoo! ローカルサーチ API**: Yahoo! JAPAN の電話帳・店舗データ。上の事業所は「○○ △△事業所」で 1 件ヒット（2026-10-18 確認）。駅名をかなで入れても、その駅周辺の施設が返る。Client ID（appid）の登録だけで使え、無料公開サービスでの利用は無料。1 アプリ 5 万リクエスト/日
- **Google Places API（Text Search）**: 収録範囲は Google Maps と同一。Google Cloud の課金登録と API キーが要る。個人規模なら月間無料枠に収まるが、キーが漏れたときの課金リスクを抱える
- **Nominatim 継続 + クエリ整形**（法人格の除去など）: 本件はデータ欠落なので救えない
- **OSM 系の別サービス**（Photon、Pelias）: データが同じなので結果も同じ

## 決定

Yahoo! ローカルサーチ API を使う。Nominatim は外す。

- 呼び出しは JSONP（`callback` パラメータ + `<script>` 挿入）。API は CORS ヘッダを返さないため `fetch` できない（2026-10-18 に `Origin` 付きで確認。`Access-Control-Allow-Origin` なし）。VPS にプロキシは置かない
- appid はビルド時に埋め込む（Vite の `VITE_YAHOO_APPID`、`.env.local`）。ブラウザから呼ぶ以上 URL に載るので秘匿はしない。YOLP の JavaScript 地図 API も同じ前提で appid を公開している
- 施設検索を呼ぶのは Enter 確定時のまま。Nominatim の規約による制約はなくなったが、「入力中は住所、Enter で施設」の 2 経路は変えない。1 日 5 万件の上限には届かないので、入力中にも呼ぶ変更は後からできる
  - 追記（2026-10-19）: 入力中にも呼ぶ形に変更した。住所と施設を 1 リストに並べ、Enter は廃止。IME 変換中は呼ばない。詳細は [search.md](../requirements/search.md)
- クエリの法人格略号 `（株）` `(株)` `（有）` `(有)` は空白に置き換えて送る。上の事業所で確認: 「○○（株）△△事業所」は 0 件、「○○ △△事業所」は 1 件。削除にすると「○○△△事業所」になり、これも 0 件
- 帰属表示は候補リスト末尾に「Webサービス by Yahoo! JAPAN」（公式スニペット A。`https://developer.yahoo.co.jp/sitemap/` へのリンク）

## 影響

- 規約上の懸念が 1 つ残る。FAQ は「一般公開された無償のサービス」を無料とし、「非公開サイト・イントラネット」は有償版 YOLP Premier の対象としている。このアプリは Tailscale 内からしか到達できず、文面上は非公開に当たる。自分用・1 日数件の利用として進めるが、Yahoo から指摘があれば止める。止めても地図タップで地点は置けるので、経路探索は止まらない
- 帰属表示のガイドラインは「アプリケーションの下部」を指定している。候補リスト末尾は厳密には異なる。地図全面のアプリに常設すると地図を隠すため、施設検索の結果が出ている間だけ表示する
- Mac に `.env.local` が要る。VPS には何も増えない
- Nominatim の 1 秒間隔待ちが不要になり、`src/api/nominatim.ts` は削除する
- 候補の出典表示が「© OpenStreetMap contributors」から Yahoo のクレジットに変わる。地図タイルの帰属（MapLibre の AttributionControl）は変わらない
