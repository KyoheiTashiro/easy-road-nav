# UI 設計（編集モード・共通部品）

要件は [map-display.md](../requirements/map-display.md) [search.md](../requirements/search.md) [routing.md](../requirements/routing.md)。ここでは画面・操作・状態の「どう作るか」。ナビ中の画面は [navigation.md](navigation.md)。

## 画面モード

`edit`（経路編集）・`navigation`（案内中）・`settings`（設定）・`home`（自宅設定）の 4 つ。trip store の `mode` で切替。

- `edit` → `navigation`: 「案内開始」（[navigation.md](navigation.md) の開始手順）
- `navigation` → `edit`: 「終了」（確認なし）または到着。経路・地点はそのまま残り、再度「案内開始」できる。GPS watch は継続
- `edit` → `settings`: 検索欄の下の歯車。経路・地点はそのまま残る（[設定画面](#設定画面)）
- `settings` → `edit`: 「戻る」
- `settings` → `home`: 「自宅を設定」/「変更」
- `home` → `settings`: 自宅を選んで保存したとき、または「戻る」（[自宅設定モード](#自宅設定モード)）

`settings` `home` は `edit` の入れ子。どちらからも `navigation` へは行かず、`edit` へは `settings` を経由して戻る。戻り先を記憶する state は持たない（遷移元が 1 つずつしかない）。

## 初期表示

- 起動と同時に `watchPosition` 開始（[現在地](#現在地)）。URL に地点がなければ初回 fix で `easeTo`（zoom 15）。URL に地点があれば探索結果の `fitBounds` が優先
- 初回 fix 前・権限拒否時の中心は東京駅 zoom 10

## 地図スタイル

- OpenFreeMap `liberty`。`prefers-color-scheme: dark` なら `dark`。`matchMedia` の `change` で `map.setStyle` し実行中も追従
- `setStyle` は自前の source / layer とラベル上書きを消す → `style.load` のたびに同じ初期化関数を呼ぶ（経路レイヤー・現在地レイヤー・ラベル上書き）
- ラベル上書き: `text-field` を持つレイヤーのうち `ref` シールド以外を `["coalesce", ["get", "name:ja"], ["get", "name"]]` に置換（付属スタイルは「ローマ字 + 日本語」併記）
- UI 側のダークは StyleX トークンの `@media` で自動。経路線の色（青 / オレンジ）は両テーマ共通

## 編集モードのレイアウト

地図フルスクリーン。オーバーレイは 5 つ。

- 上部: 検索欄 2 段（出発地 / 到着地）
- 下部: ボトムシート
- 左下（ボトムシートの直上）: MapLibre `ScaleControl` + 帰属表示（compact）
- 左上（検索欄の下）: MapLibre `NavigationControl`（コンパスのみ、`visualizePitch`）。アイコンは自前 SVG（赤い北針の円形）に CSS で差替、MapLibre の白地・影は消す（40px）。押下で北上・pitch 0。ナビ中は外す（heading 追従と衝突するため）
- 右下（ボトムシートの直上）: 現在地ボタン（[現在地](#現在地)）。40px の円、背景 `colors.background`、影なし。MapLibre の `bottom-right` コントロールに入れ、縮尺・出典と同じ CSS の `margin-bottom` でシートのピーク高の上に置く。スワイプ中はシートの下に隠れ、展開中は描画しない

### ボトムシート

2 段（ピーク = `layout.peek`（経路なしは `layout.peekEmpty`）、展開 = 75dvh = `layout.half`）。CSS `max-height` transition のみ、ライブラリ不使用。

ピーク行は 2 行のグリッド。1 行目 = 所要時間・距離 +「案内開始」、2 行目 = 細い道・有料・右左折をシート幅いっぱいに並べる（ボタンの横に置くと 3 項目が揃ったとき重なる）。

開閉の操作:

- タップ: ハンドル（`<button aria-expanded>`）とピーク行の文字部分で切替。「案内開始」はタップ対象外
- スワイプ: `touchmove` で `max-height` を指に追従（ピーク高〜75dvh にクランプ、追従中は transition なし）。`touchend` で縦移動 30px 以上なら方向で確定、未満なら元に戻る。`touchcancel` でも追従を解除。展開中の上方向はリストのスクロールに任せシートを触らない。リスト内で始めたタッチでリストがスクロール済み（`scrollTop > 0`）なら下方向は無視（ハンドル上なら閉じる）
- 地図タップ: 展開中は地点ポップアップを開かず収納だけ
- 再展開は先頭から（展開時に body の `scrollTop` を 0 に）
- 展開・収納のたびに `fitBounds` し直す（[探索](#探索)）

内容:

- **ピーク**: サマリ 2 行 + 「案内開始」ボタン
  - 1 行目: 所要時間（24px 太字）+ 距離（16px）
  - 2 行目: 細い道（あれば オレンジ背景チップ「`NarrowIcon` 細い道 x.x km」、なければ緑字「細い道なし」）/ 有料 x.x km（あれば）/ `TurnsIcon` 右左折 n 回。[アイコンのみ表示](#アイコンのみ表示) ON なら チップ「`NarrowIcon` x.x km」（なければチップ自体を出さない）/ 有料 x.x km / 「`TurnsIcon` n 回」
  - 探索中はスピナー + 「探索中…」、地点が揃っていなければ「出発地と到着地を設定してください」
  - 「案内開始」: 経路がないときは出さない。高さ 52px・文字 16px。GPS fix なし・エラー中は文言「GPS 待ち」で無効、開始処理中も無効
- **展開**: 上から順に。2 以降は上罫線で区切る
  1. 地点リスト（タイムライン）。検索欄と同じ記号を縦線で繋ぐ: 出発地は中空の丸（`FromIcon`）、経由地は番号、到着地はピン（`ToIcon`）。色は地図マーカーと同じ（`tokens` の `marker`）、未設定は `colors.border`。塗り丸にしない（地図マーカーと紛れ、見た目も重い）。各行: 記号・地点名・削除ボタン。経由地行は ▲▼ 並べ替えボタン付き。未設定は薄字「<役割>未設定（地図をタップ）」。役割名は記号の `aria-label`
  2. 「高速・有料を避ける」トグル（経路ごとに切り替える探索条件なのでここに残す。端末設定は[設定画面](#設定画面)）
  3. 代替経路カード（経路が 2 本以上のときだけ。最大 3 枚）。各カードはピーク行と同じ 2 行、1 行目の先頭にラベル「推奨」/「代替 n」。左縁 4px、選択中は枠が accent 色。タップで本線入替。シートは開いたまま（閉じると選択結果が見えず「選択されていない」と誤認する）
  4. 案内文リスト（`StepList`。GraphHopper の返却全部（`sign 0` 含む）。ステップごとに 距離 / 指示 / 道路名。細い道区間に入るステップは先頭に「⚠ 細い道」、行全体に薄いオレンジ背景 `colors.narrowBackground`。アイコンのみ表示 ON なら「⚠ 細い道」の代わりに `NarrowIcon`（`colors.narrow` 色、14px）だけ）

表示文字列（距離・時間・時刻）は `src/shared/format.ts` に集約。所要時間は「1 時間 20 分」「25 分」「1 分」。

### 検索欄

出発地・到着地の入力 2 段。各欄は「現在の地点名の表示」と「住所検索・施設名検索」を兼ねる。経由地はここでは扱わない（地図タップ → ポップアップ）。

- 未フォーカス: 地点名を表示（逆ジオ中は「…」、未設定なら placeholder「出発地を検索」）。右端の × で地点を削除（`onDelete` と同じ。削除後は空のまま）
- フォーカス: 空欄から検索開始。Enter（`<form onSubmit>`。入力欄は `enterKeyHint="search"` でスマホキーボードに「検索」キー）または候補リスト先頭の「🔍 「<入力文字列>」で検索」行（入力あり かつ そのクエリで未検索のとき表示。タップは Enter と同じ）で国土地理院 住所検索と Yahoo! ローカルサーチ 施設名検索を 1 回ずつ並行して呼ぶ（[search.md](../requirements/search.md)）。入力中は呼ばない。IME 変換確定の Enter は `keydown` で `isComposing || keyCode === 229` を見て submit させない。再 Enter で前回の飛行中リクエストを `AbortController` で中断。検索 state はフォーカス中の欄 1 つ分だけ持つ
- 住所検索の結果は素の GeoJSON Feature 配列（FeatureCollection ではない）。`geometry.coordinates` = `[lng, lat]`、`properties.title` = 表示名。件数上限なし。全件リスト表示（リストは `maxHeight: 40vh` でスクロール）
- 1 つのリストに施設候補（最大 100）→ 住所候補（全件）の順で並べる。見出しは付けない。返った方から順に表示し、片方が 0 件・失敗でももう片方は出す。Enter 後に入力を変えると結果は消え、再 Enter まで出ない
- 候補タップ → その欄の役割（出発地 / 到着地）に直接セット。ポップアップ・`flyTo` はしない（探索後の `fitBounds` に任せる）。欄のフォーカスを外す
- 出発地欄の候補リスト先頭に「現在地」行（fix あり・GPS エラーなしのとき）。選択で最新 fix を出発地に置換（地点名は逆ジオ）
- 入力が空のとき（`query.trim() === ""`）は「現在地」の下に「自宅」行（登録済みのとき。家アイコン + 「自宅」+ 地点名）と検索履歴行（地点名のみ。新しい順、最大 5）を出す。到着地欄は「自宅」→ 履歴。1 文字でも入力すると消える
- 住所検索・施設名検索の候補タップは、その地点を検索履歴の先頭に入れる（`saved.ts` の `pushHistory`）。「現在地」「自宅」「履歴」行のタップは入れない
- 失敗（ネットワーク・非 2xx）→ トースト「住所検索に失敗しました」/「施設検索に失敗しました」。もう片方の候補は出る。地図タップで代替
- blur で候補リストを閉じる。候補タップより blur が先に来るので 150 ms 遅らせる
- カードの下、右寄せに歯車の丸ボタン（40px、`SettingsIcon` 24px、`colors.background` + カードと同じ影、aria-label「設定」）。コンパスは左上に置き、右側は歯車だけにする。タップで `settings` モード（[設定画面](#設定画面)）。常時見える入口にし、ボトムシートは経路情報だけにする。候補リスト表示中と自宅設定モードでは出さない

### 地点ポップアップ

地図タップで開く MapLibre `Popup`。1 つだけ（開いたまま別地点タップで置換）。

- 内容: 地点名（逆ジオ結果。取得中は「…」）+ ボタン 3 つ「出発地にする」「到着地にする」「経由地に追加」
- 逆ジオ: 国土地理院 `LonLatToAddress`。表示は `results.lv01Nm`（町丁目）のみ。市区町村名は出さない（`muniCd` → 名前の変換表 `muni.js` が別途必要なため v1 は不採用）
- 逆ジオ失敗・海上（応答 `{}`）→ 地点名は座標 `35.68123, 139.76712`（小数 5 桁）。探索は止めない
- 「出発地にする」「到着地にする」は既存地点を無確認で置換
- 「経由地に追加」は末尾に追加。経由地 5 件のとき無効表示
- ボタン押下でポップアップを閉じる。別地点タップは置換（閉じない）。閉じるだけなら × ボタン
- `home` モードではボタンは「自宅にする」1 つ。地点名が逆ジオ中（null）の間は無効。押下で自宅を保存し `settings` へ戻る

### 地点マーカー

MapLibre DOM `Marker`。出発地（緑）・到着地（赤）・経由地（青、番号付き）。ドラッグ不可。
マーカータップ → 「削除」ボタンだけのポップアップ。削除で再探索。
自宅マーカー（家アイコン）は登録済みなら全モードで常時表示。タップしても何も起きない。

### 現在地

- 起動時に `watchPosition` 開始（`enableHighAccuracy: true`）。アンマウントまで常時継続。ナビ終了でも止めない
- 現在地マーカー: 青ドット + 精度円（GeoJSON `circle` layer、半径は `accuracy` をズームでメートル換算）。編集・ナビとも常時表示
- 出発地の既定 = 現在地。URL に `from` がなければ初回 fix で 1 回だけ出発地にセット（地点名は逆ジオ）。以後 fix に追従しない（追従すると毎 fix 再探索。ナビ開始時に最新 fix で置換される: [navigation.md](navigation.md)）。× で消したら再セットしない
- 出発地欄の候補「現在地」: 最新 fix を出発地に置換（地点名は逆ジオ）。fix なし・GPS エラー中は非表示
- 権限拒否・取得失敗 → トースト「現在地を取得できません」（`error` の立ち上がりで 1 回）。「現在地」候補を隠し「案内開始」を無効化。ナビ中の失敗はトーストのみ、ナビ継続
- 現在地ボタン（編集・自宅設定モード）: 最新 fix へ `easeTo`。zoom は `max(現在の zoom, 15)`、bearing・pitch は変えない。寄せるのは 1 回だけで、以後の fix には追従しない（追従は地図を動かすたびに解除する状態が要り、編集中は経路の確認でパンすることが多い）
  - アイコン: 照準（十字の入った円、中心は塗り）
  - fix なし・GPS エラー中はグレーで無効（「案内開始」の「GPS 待ち」と同じ条件）

## 設定画面

`mode === "settings"`。検索欄の下の歯車で開く。地図の上に不透明なパネル（`position: fixed; inset: 0`、`colors.background`）を重ねる。地図は描画したまま隠すだけ（アンマウントすると MapLibre の再初期化とタイル再取得が要る）。検索欄・ボトムシートは出さない。トーストはパネルより上。

端末に保存する設定だけを置く。経路ごとに変える条件（高速・有料）はボトムシートに残す。

- ヘッダー: 「戻る」ボタン（自宅設定モードの「戻る」と同じ見た目）+ 見出し「設定」
- 行 1「自宅」: 登録済みなら `HomeIcon` + 地点名 + 「変更」ボタン、未登録なら「未登録」+ 「自宅を設定」ボタン。どちらも `home` モードへ（ボトムシートにあった自宅行をそのまま移す）
- 行 2「細い道・右左折をアイコンだけで表示」: トグル（`<input type="checkbox">`。ボトムシートの「高速・有料を避ける」と同じ見た目）。ON/OFF は即保存（[アイコンのみ表示](#アイコンのみ表示)）
- 行 3「対応地域」: 地図データに含む都道府県を静的文で列挙（「対応地域: 東京・神奈川・…・新潟」、12px、薄め）。値は `Settings.tsx` の定数。地域を足したら手で更新する（[runbook.md](../runbook.md) 5 章）
- 「戻る」→ `edit`。保存ボタンは置かない（各行で即保存）
- ナビ中は入れない（入口がボトムシートにしかない）

### アイコンのみ表示

saved store の `iconOnly`（`localStorage` キー `iconOnly`、既定 false）。細い道・右左折の表示から文言を抜き、アイコンと数値だけにする。ピーク行の横幅が足りず折り返す機種向け。

| 場所                                | OFF（既定）                                                               | ON                                                    |
| ----------------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------- |
| サマリ 2 行目（ピーク・代替カード） | 「`NarrowIcon` 細い道 x.x km」/「細い道なし」/「`TurnsIcon` 右左折 n 回」 | 「`NarrowIcon` x.x km」/（なし）/「`TurnsIcon` n 回」 |
| 案内文リストの行頭                  | 「⚠ 細い道」                                                              | `NarrowIcon`（`colors.narrow` 色、14px）              |

- 有料 x.x km・所要時間・距離・案内文本文・ナビ HUD の「細い道を走行中」バナーは変えない（走行中は一瞥で読める文言が要る）
- 文言を消した要素には OFF 時の文言を `aria-label` で付ける（「細い道 1.2 km」「右左折 5 回」「細い道」）。見た目だけの切替で意味は落とさない
- 発話は変えない（音声に「アイコン」はない）
- 各表示部品が `useSaved(s => s.iconOnly)` を直接購読する。props で引き回さない（RouteSummary は BottomSheet から props を受けるが、この値は 2 部品に散るので store 購読に揃える）

## 自宅設定モード

`mode === "home"`。地図フルスクリーンに上部の検索カード 1 枚だけを重ねる。ボトムシートは出さない。経路レイヤーは描画データを空にして隠す（state は変えない。`settings` へ戻ると再表示）。地点マーカー（出発地・経由地・到着地）も同様に隠す。入口は設定画面の「自宅を設定」/「変更」。

- 上部カード: 「戻る」ボタン + 入力欄 1 つ（placeholder「自宅を検索」）。入力欄の動きは編集モードの検索欄と同じ（住所検索・施設名検索を並行）。空欄候補は「現在地」→ 検索履歴。「自宅」行は出さない
- 候補タップ（住所・施設名・履歴・現在地）→ その地点へ `easeTo`（zoom は `max(現在の zoom, 15)`）するだけ。保存もポップアップもしない（自宅は地図タップでだけ決める）。住所・施設名の候補は検索履歴にも入れる
- 地図タップのポップアップ「自宅にする」→ 自宅を保存、トースト「自宅を登録しました」、`settings` へ戻る（登録結果が設定画面の自宅行で見える）
- 地図タップ → ポップアップ「自宅にする」（[地点ポップアップ](#地点ポップアップ)）
- 入ったとき自宅が登録済みなら `easeTo`（自宅、zoom 15）。未登録ならカメラはそのまま
- 「戻る」→ `settings`。ポップアップを閉じる。保存しない
- ナビ中は入れない（入口が設定画面にしかない）
- 縮尺・出典（左下）と現在地ボタン（右下）は画面下端に置く（シートがないので、地図コンテナの `data-mode="home"` で `margin-bottom` を safe-area + 10px に上書き）。コンパスは 1 行の検索カードの直下に上げる

## 探索

- 自動。出発地 + 到着地が揃った時点、および地点・経由地・順序・有料トグルの変更のたびに再探索
- 飛行中リクエストは `AbortController` で中断してから次を投げる。中断はトーストしない
- ローディング表示: サマリ行にスピナー 1 個
- 経由地なし → `alternative_route` 最大 3 本、あり → 1 本（[route-model.md](route-model.md) の契約）
- 新しい経路が返ったら `fitBounds`（下パディング = シートの高さ。収納時はピーク高、展開時は 75dvh）。ボトムシートの展開・収納でも fit し直す。代替切替・トグル変更・再探索の結果ではカメラを動かさない（「新しい経路」= 地点集合が変わった探索のみ）。trip store が fit 済みの地点集合を覚えておき、違う集合の結果が返ったときだけ fit の合図を出す
- 失敗（400 / ネットワーク）→ トースト 1 種「経路を探索できません」。経路表示は空にする

## 経路レイヤー

GeoJSON source 2 つ、line layer 3 つ。描画分割は [route-model.md](route-model.md)。

| source        | layer              | 内容                            | 見た目                               |
| ------------- | ------------------ | ------------------------------- | ------------------------------------ |
| `alternative` | `alternative-line` | 非選択の代替経路（全区間 1 本） | 青、薄い、細い                       |
| `route`       | `route-wide`       | 選択経路の広い道区間            | 青 実線                              |
| `route`       | `route-narrow`     | 選択経路の細い道区間            | オレンジ 破線、`route-wide` より太い |

`route` source の feature は `kind` プロパティで filter。短区間無視は描画に適用しない。

## 状態（store）

zustand の store を関心ごとに分ける（`trip/trip.ts` 地点・探索結果・画面モード・GPS、`navigation/navigation.ts` ナビ、`settings/saved.ts` 端末保存、`shared/toast.ts`）。UI は 1 値 1 セレクタで購読し、操作はアクション（起きた事象の名前）で行う。フィールドとアクションは各 store の型が正。

- ポップアップは地図タップとマーカータップの 2 種を 1 フィールドの判別共用体で持つ（同時に開かないことを型で保証する）
- 自宅・検索履歴・アイコンのみ表示は `localStorage` が正で、store は起動時に読んだ写し。URL には入れない。ミュートはセッション内のみ
- 派生値（表示する経路・細い道区間・探索中か）はセレクタで出す。`useMemo` は書かない（React Compiler）
- 探索結果は、探索したときの地点集合キーと有料トグルを一緒に持つ。表示する経路は、地点が揃い、そのキーとトグルが現在と一致するときだけ。一致しなければ探索中。地点が欠けたら即空になるので、effect 内で同期 setState しない
- 地点集合キーは地点座標の文字列化。label を含めないので、逆ジオで地点名が入っても再探索しない
- URL: `from` `to` `vias` `notoll` の変更で `history.replaceState`。初期化時にクエリから復元し探索（不正な地点はその地点だけ無視、`via` は先頭 5 件。parse 規則は `trip/url.ts`）。ナビ開始で出発地が現在地に置換されたときも更新する
- 探索は地点集合キー・有料トグル・ナビ中かの変化で走る。ナビ終了時は結果を捨てて探索し直す（リルート後の途中からの経路を残さない）

1 つだけ。新しいメッセージで置換。4 秒で自動消去（タイマーは `Toast.tsx`）。画面上部（ナビ中は NavigationHud の下）。
