# 地図表示

## 画面

画面構成・操作の詳細は [design/ui.md](../design/ui.md)。

- スマホ・タブレットの縦画面前提。PC ブラウザでも動くが最適化しない
- 地図がフルスクリーン、操作 UI はオーバーレイ
- PWA: `manifest.json`（standalone、アイコン1枚）のみ。ホーム画面追加で全画面起動。Service Worker・オフラインは無し

## タイル

- OpenFreeMap のベクトルタイル + 付属スタイル `liberty`。MapLibre GL JS で描画
- ダークモード: OS 設定（`prefers-color-scheme: dark`）に追従し `dark` スタイル + UI ダーク。実行中の切替にも追従。手動トグルなし
- ラベルは日本語のみ（付属スタイルは「ローマ字 + 日本語」併記なので `text-field` を上書き。方法は [design/ui.md](../design/ui.md)）
- 帰属表示: OpenStreetMap contributors / OpenFreeMap

## 経路の描画

- 広い道区間: 青の実線
- 細い道区間: オレンジの破線、広い道より太い
- 代替経路: 本線より薄い色、選択で本線と入れ替え
- 出発地・到着地・経由地: マーカー。経由地は番号付き

## 案内文リスト

- ステップごとに 距離 / 指示 / 道路名。GraphHopper の返却を全部出す（直進・道路名変更の `sign 0` も含む）
- 細い道区間に入るステップの先頭に「⚠ 細い道」

## 経路サマリ

- 距離 / 所要時間。所要時間は「1 時間 20 分」「25 分」、1 分未満は「1 分」（ナビ中の残り時間も同じ）
- 有料区間を含むとき「有料区間 x.x km」。地図上の強調はしない
- 細い道区間の合計「細い道 x.x km」。0 なら「細い道なし」
- 「右左折 n 回」。直進・経由地・目的地・分岐の「右寄り/左寄り」は数えない

## URL 共有

- 形式: `?from=lat,lng&to=lat,lng&via=lat,lng|lat,lng&notoll=0`。座標は小数 5 桁。`notoll` 省略は避ける（既定）、`0` のみ高速・有料を使う
- 地点名・選択中の代替経路は含めない（地点名は逆ジオで再取得、代替経路はデータ更新で変わる）
- URL を開くと経路探索まで自動実行
- 不正な値（形式違い・緯度経度範囲外）はその地点だけ無視。`via` は先頭 5 件
