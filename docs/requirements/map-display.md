# 地図表示

## 画面

画面構成・操作の詳細は [design/ui.md](../design/ui.md)。

- スマホ・タブレットの縦画面前提。PC ブラウザでも動くが最適化しない
- 地図がフルスクリーン、操作 UI はオーバーレイ
- PWA: `manifest.json`（standalone、アイコン1枚）のみ。ホーム画面追加で全画面起動。Service Worker（`public/sw.js`）が app shell（`/` `/assets/*` `/icon.png` `/manifest.json`）を Cache Storage から即返す（iOS standalone 起動時の HTML 到着待ちで白画面が数秒出るのを防ぐ）。`/assets/*` は cache-first、それ以外は stale-while-revalidate（デプロイ後の初回起動は旧版、次回起動から新版）。`/` をキャッシュに置く前に HTML が参照する `/assets/*` を揃え、揃わなければ置かない（デプロイの `rsync --delete` で旧 assets が消えると、キャッシュした旧 HTML の JS が 404 になり白画面のまま戻らない）。`cache: "no-store"` の要求（`useUpdateCheck`）はネットワークから取得してキャッシュを更新する（キャッシュを返すと更新を検知できない）。SW からの取得は `cache: "no-cache"`（`tailscale serve` は Cache-Control を付けず、HTTP キャッシュが heuristic で旧版を返し続ける）。`/gh/*` と外部オリジンは素通し。オフライン対応は目的外

## タイル

- OpenFreeMap のベクトルタイル + 付属スタイル `liberty`。MapLibre GL JS で描画
- ダークモード: OS 設定（`prefers-color-scheme: dark`）に追従し `dark` スタイル + UI ダーク。実行中の切替にも追従。手動トグルなし
- 運転に不要で描画コストが高い層（建物 3D、施設アイコン、歩道・小道）は `style.load` 時に非表示にする。建物は平面塗りを全縮尺に伸ばして残す。駅は目印として残す。対象の id は `src/map/mapLayers.ts`
- ラベルは日本語のみ（付属スタイルは「ローマ字 + 日本語」併記なので `text-field` を上書き。方法は [design/ui.md](../design/ui.md)）
- 帰属表示: OpenStreetMap contributors / OpenFreeMap

## 経路の描画

- 広い道区間: 青の実線
- 細い道区間: オレンジの破線、広い道より太い
- 代替経路: 本線より薄い色、選択で本線と入れ替え
- 出発地・到着地・経由地: マーカー。経由地は番号付き

## 案内文リスト

- ステップごとに 距離 / 指示 / 道路名。GraphHopper の返却を全部出す（直進・道路名変更の `sign 0` も含む）
- 細い道区間に入るステップの先頭に「⚠ 細い道」（[設定画面](#設定画面)のアイコンのみ表示 ON ならアイコンだけ）

## 経路サマリ

- 距離 / 所要時間。所要時間は「1 時間 20 分」「25 分」、1 分未満は「1 分」（ナビ中の残り時間も同じ）
- 有料区間を含むとき「有料区間 x.x km」。地図上の強調はしない
- 細い道区間の合計を細い道アイコン + 「細い道 x.x km」。0 なら「細い道なし」
- 右左折の回数を左右二股矢印アイコン +「右左折 n 回」。直進・経由地・目的地・分岐の「右寄り/左寄り」は数えない

## 設定画面

端末に保存する設定を 1 画面にまとめる。検索欄の下の歯車から開く。経路ごとに変える条件（高速・有料を避ける）はボトムシートに残す。

- 自宅の登録・変更（[search.md](search.md)）
- 「細い道・右左折をアイコンだけで表示」トグル（既定 OFF）。ON のとき経路サマリの「細い道 x.x km」「右左折 n 回」、案内文リストの「⚠ 細い道」から文言を消し、アイコン（+ 数値）だけにする。細い道が無い経路では細い道の表示自体を出さない。有料・所要時間・距離・案内文本文・ナビ中の「細い道を走行中」バナー・音声は変えない。見た目の切替のみで、`aria-label` に元の文言を残す

## URL 共有

- 形式: `?from=lat,lng&to=lat,lng&via=lat,lng|lat,lng&notoll=0`。座標は小数 5 桁。`notoll` 省略は避ける（既定）、`0` のみ高速・有料を使う
- 地点名・選択中の代替経路は含めない（地点名は逆ジオで再取得、代替経路はデータ更新で変わる）
- URL を開くと経路探索まで自動実行
- 不正な値（形式違い・緯度経度範囲外）はその地点だけ無視。`via` は先頭 5 件
