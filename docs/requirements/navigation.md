# ナビゲーション

経路確定後の「案内開始」で入る。スマホを車内で使う前提。状態機械・発話文言・カメラの詳細は [design/nav.md](../design/nav.md)。

## 現在地

- Geolocation API `watchPosition`（高精度）。HTTPS 必須。起動時に開始し、アプリ表示中は常時継続（ナビ終了でも止めない）
- 現在地マーカーを常時表示。出発地の既定は現在地。出発地欄の候補「現在地」で再設定できる

## 追従

- 地図中心を現在地に追従
- 進行方向ヘッドアップ（地図を進行方向に回転）
- 進行方向のソース: 経路線の方位（進捗点が乗る線分の向き）。経路外れ中は直近 2 fix の方位にフォールバック（fix 間の移動が方位算出最小移動 以上のときのみ更新、CONTEXT.md 調整値）。GPS `heading` は使わない（iOS で停止時 null、低速で不安定）
- 画面消灯防止（Wake Lock API）。非対応ブラウザでは何もしない

## 進捗判定

ナビ中の位置判定の土台。案内・経由地通過・細い道警告・到着はすべてこの累積距離で判定する。

- 現在地 → 経路線上の最近傍点 → 経路上の累積距離（進捗）。データ構造と計算は [route-model.md](../design/route-model.md)（自前 haversine + 線分射影、全線分走査）
- GPS `accuracy` が進捗採用精度（CONTEXT.md 調整値）以上の fix は進捗・案内・経路外れ判定に使わない
- 進捗は単調増加のみ受け入れる（後戻りは無視。実際に戻った場合はリルート判定に任せる）
- 案内地点・経由地・細い道区間の開始点は経路上の累積距離を持ち、進捗との差で残り距離を出す
- 経由地通過: 進捗が経由地の累積距離を超えた時点
- 到着: 到着地までの残りが到着判定（CONTEXT.md 調整値）未満で「到着」を表示・発話し、ナビ終了

## 次の案内

- 画面上部に 次の指示 / 残り距離 を常時表示
- 案内トリガー: 案内地点の 300 m 手前で予告、50 m 手前で直前案内（CONTEXT.md 調整値）

## 細い道進入前警告

- 細い道区間の 300 m 手前で画面警告 + 音声「この先、細い道です」
- 出発地に接する先頭区間は警告しない。到着地に接する末尾区間は「この先細い道、目的地付近」
- 細い道区間を走行中は画面上部にバナー表示

## 音声案内

- Web Speech API（`speechSynthesis`）、日本語
- 案内トリガー・細い道警告と同じタイミングで発話
- iOS Safari はユーザー操作後でないと発話できない制約あり。「案内開始」タップで初期化する
- ミュートトグル1個
- 競合時は単純キュー（発話中は待ち、順番に全部言う）。同一メッセージは再発話しない

## 自動リルート

- 現在地が経路線から経路外れ距離を超える fix がリルート連続回数だけ続き、かつ GPS `accuracy` が 50 m 未満のときリルート（CONTEXT.md 調整値）。GPS ノイズでの誤発火防止
- リルート要求中は再リルートしない（応答が返るまで）
- 出発地は現在地から進行方向へリルート前方オフセットだけずらした点（CH のため `heading` が使えず、U ターン指示が出るのを防ぐ）。進行方向は「追従」と同じソース（経路外れ中なので実質 直近 2 fix の方位）
- リルート失敗（サーバ不達・経路なし）は旧経路のまま案内継続 + トースト。次の経路外れ判定で再試行
- 未通過の経由地と到着地はそのまま
- 有料回避トグル状態を引き継ぐ

## 既知の限界

- 案内開始時（初回探索）は車の向きが不明。経路が背後方向へ出て U ターンから始まることがある。何もしない。進まなければ経路外れ → リルート（前方オフセットあり）が拾う

## v1 に含めない

- 車線案内、交差点拡大図
- 渋滞・通行止め情報
- バックグラウンド動作（画面 OFF 時の案内）
