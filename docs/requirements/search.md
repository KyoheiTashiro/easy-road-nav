# 地点検索

## 住所検索

- 国土地理院 住所検索 API（`msearch.gsi.go.jp/address-search/AddressSearch?q=`）
- 出発地・到着地の入力欄に住所を入れ、候補リストから選択するとその役割に直接セット。施設名検索は対象外
- 経由地は地図タップで指定（入力欄なし）
- 日本国外の結果は出ない（API 仕様）
- API は住所データ主体。駅・施設は末尾に少数混ざる程度で、駅名が町名と違う駅は住所としては当たらない。施設名は下の施設名検索で引く

## 施設名検索

- Yahoo! ローカルサーチ API（`map.yahooapis.jp/search/local/V1/localSearch`）。電話帳・店舗データ主体で、駅・店のほか事業所も名称で引ける。駅名をかなで入れても、その駅周辺の施設が返る。採用理由と Nominatim からの切り替え経緯は [ADR-0003](../adr/0003-poi-geocoder-yahoo.md)
- Enter（スマホキーボードの「検索」キー）か候補リストの「🔍 「<入力>」で検索」行のタップで住所検索と並行して 1 回呼ぶ。入力中は呼ばない。IME 変換確定の Enter では呼ばない
- 結果は住所検索の候補と同じリストに出す。施設（最大 100 件 = API 上限）→ 住所（全件）の順。表示名は応答の `Name`（例「○○株式会社 △△事業所」「○○駅（JR）」）。候補タップで役割にセット
- クエリの法人格略号 `（株）` `(株)` `（有）` `(有)` は空白に置き換えて送る。略号付きのままだと 0 件になる
- 0 件のときは何も出さない（住所候補だけ並ぶ）。失敗はトースト「施設検索に失敗しました」
- 呼び出しは JSONP。API が CORS ヘッダを返さないため `fetch` は使えない。appid はビルド時に埋め込む（[infrastructure.md](infrastructure.md)）
- 利用条件（[FAQ](https://developer.yahoo.co.jp/webapi/map/faq.html)、[クレジット表示ガイドライン](https://developer.yahoo.co.jp/attribution/)）で守る点
  - 1 アプリケーション 5 万リクエスト/日。短時間の大量リクエストは制限されることがある。Enter ごとに 1 回なので自分用なら桁違いに少ない
  - クレジット表記「Webサービス by Yahoo! JAPAN」を `https://developer.yahoo.co.jp/sitemap/` にリンクして表示。候補リスト末尾に出す
  - 無料の条件は「一般公開された無償のサービス」。Tailscale 内からしか到達できないこのアプリは、文面上は有償対象の「非公開サイト」に当たりうる。自分用として進める判断と、止めるときの代替は ADR-0003
- 既知の限界: 提供終了・規約変更で使えなくなる可能性がある。自分用なので許容し、代替は地図タップ

## 地図タップ

- 地図をタップ（MapLibre `click`）で地点を置く。長押しは使わない
- 逆ジオコーディング: 国土地理院 逆ジオ API（`mreversegeocoder.gsi.go.jp/reverse-geocoder/LonLatToAddress`）で市区町村 + 町字を表示。番地までは出ない

## 現在地

- 出発地の既定は現在地（起動後の初回 fix。URL 指定があればそちら）
- 出発地欄の候補「現在地」で再度セットできる（[navigation.md](navigation.md) の Geolocation を共用）

## 自宅

- 自宅を 1 件、端末（`localStorage`）に登録できる。登録は設定画面（検索欄の下の歯車から開く）の「自宅を設定」で開く自宅設定画面で行う（[design/ui.md](../design/ui.md)）
- 自宅設定画面では住所検索・施設名検索・地図タップ・現在地のどれでも地点を選べる。選んだ時点で保存し、設定画面に戻る
- 登録済みなら、出発地・到着地の入力欄をフォーカスして空のとき、候補の先頭に「自宅」行を出す（出発地欄では「現在地」の次）。タップでその役割にセット
- 変更は同じ画面で再登録（上書き）。削除機能はない
- 端末ごとに別。URL 共有には含めない

## 検索履歴

- 住所検索・施設名検索の候補をタップして地点にした記録を、新しい順に 5 件（検索履歴件数）端末に保存する。自宅設定画面での候補タップも含む
- 地図タップ・現在地・自宅・履歴行からセットした地点は記録しない。履歴には名前付きの地点だけが並ぶ
- 同じ座標の地点は 1 件にまとめ、最新の位置に置く
- 入力欄が空のとき、「現在地」「自宅」の下に履歴行を出す。タップでその役割にセット
- 削除機能はない。6 件目以降は古いものから消える
- 端末ごとに別。URL 共有には含めない
